# Сетка ударов

СЕТКА УДАРОВ

English: README.md

Интерфейс запускается на английском языке. Для русского выберите
«Русский» в переключателе Language / Язык в верхней части страницы.

Запуск на этом компьютере:
  Откройте терминал в этой папке и выполните:
  ./Запустить.sh

Откроется страница в браузере. Выберите WAV, FLAC или другой файл,
поддерживаемый установленной библиотекой soundfile. Если вырезанный
фрагмент начинается на 3:16 в Audacity, укажите смещение 196 секунд.
Нажмите «Анализировать». Таблицу можно сохранить как CSV.
Закрыть программу: Ctrl+C в том же терминале.

Также можно запустить анализ в терминале:
  ./Запустить.sh /путь/к/файлу.wav --offset 196
  ./Запустить.sh /путь/к/файлу.wav --offset 196 --bpm 134

Для репеинта сравнивайте таблицы оригинала и полученного варианта,
указывая одинаковое смещение. Давайте по несколько секунд контекста
с обеих сторон. Порог подсветки можно настроить.

Значения — оценки долей алгоритмом librosa по звуку всего микса,
не точные измерения атак отдельных барабанов. Алгоритм может выбрать
соседнюю атаку, сгладить изменения и ошибиться в темпе вдвое.
При указанном BPM он используется как подсказка трекеру, а не как
жёсткая метрономная сетка. Проверяйте результат на слух. Файлы не меняются.

Для запуска нужны Python 3.10+, numpy, scipy, librosa и soundfile.
Установите зависимости: python3 -m venv .venv, затем
source .venv/bin/activate и pip install -r requirements.txt.
На Linux/macOS запуск: ./start.sh; на Windows: python beat_grid.py.
Ограничения интерфейса: файл до 256 МБ, длительность до 15 минут.
Формат проекта Audacity .aup3 не поддерживается: экспортируйте аудио.

СВЕДЕНИЕ СЕТОК ВОКРУГ ВЫДЕЛЕНИЯ

1. Выберите аудио и укажите его начало в проекте (для 2.wav — 196).
2. Нажмите «Анализировать». В таблице кнопкой «Начало» выберите начало
   нужного интервала, кнопкой «Конец» — конец нужного интервала.
   Границы можно также указать вручную в секундах по шкале проекта.
3. Нажмите «Рассчитать сдвиг». Программа возьмёт ближайшие доли по обе
   стороны выделения из общей таблицы и сравнит фактическое расстояние
   с числом интервалов, умноженным на общую медиану по файлу.
4. Если ошибка не превышает допуск (изначально 15 мс), предлагается 0.
   Иначе сдвиг равен разнице со знаком наоборот. Указаны опорные доли,
   количество интервалов, фактическое и ожидаемое расстояние.
5. Величину сдвига можно исправить вручную. «Создать WAV» скачивает
   новый файл целиком. Исходный файл не изменяется.

При сдвиге вправо программа вставляет тишину в середину выделения;
при сдвиге влево удаляет часть в середине выделения. Длина файла меняется
на величину сдвига. Правая часть сдвигается целиком. Место редактирования
может щёлкать — оно предназначено для исправления репеинтом. WAV —
32-bit float; число каналов и частота дискретизации сохраняются.

Расчёт зависит от найденных долей и общей медианы: если в песне меняется
темп или алгоритм пропустил долю, результат может быть ошибочным.
Особенно внимательно проверяйте большие сдвиги и длинные выделения.
Результат следует проверять на слух; точности до миллисекунды нет.
